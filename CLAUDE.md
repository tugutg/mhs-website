# Notes for Claude — mhs.mn website

Static one-page site in three languages (Mongolian, English, Chinese) for Material Handling Systems LLC (MHS). `docs/` is the source; `python3 tools/build_site.py docs _site` turns it into the published site.

## Hosting and deploy (since 7 Nov 2026) — read this first

- **https://mhs.mn is served by Cloudflare Pages, project `mhs-mn`** (account Tugu.tg@gmail.com, id `11367a073bab02e5947460e024a4dc6b`), by **direct upload**. www.mhs.mn redirects to mhs.mn; mhs-mn.pages.dev is the test address (kept out of search by `docs/_headers`). DNS is on Cloudflare too. The MTA-STS policy (mta-sts.mhs.mn) is a separate Cloudflare Pages project, `mhs-mta-sts`.

- **To publish:** build `_site`, then upload all of it as a new **Production** deployment of `mhs-mn` (Cloudflare dashboard → Workers & Pages → mhs-mn → Create deployment). Steps, checks and the browser method that works are in `.claude/skills/mhs-site-change/cf_deploy.md`. `docs/404.html` and `docs/_headers` are part of every upload (the build copies them).
- **Keep the repo and the live site the same:** every change that goes live is committed and merged here in the same session, and every merge to `main` that changes `docs/` is deployed. If they ever differ, the live site wins — compare before editing (see cf_deploy.md, "Before you start").

## Rules

- Keep it one static page: `docs/index.html` with inline CSS and JS, no frameworks or trackers. It is the only page anyone edits and must keep working on its own (opened straight from the repository it shows every photo and all three languages, with the switch working in place). The owner said on 2 Nov 2026 that the one-page rule is not firm: more pages may come if they serve visitors better, and each such step asks first.
- The build is the only build step: Python + Pillow, no other dependencies. It copies `docs/` as it is and adds:
  - phone-size copies of every photo in a `<figure class="slot">` (`photos/NAME-800w.jpg` …) with `srcset`/`sizes` on its `<img>`. The hero is a framed 4:3 photo beside the heading since 28 Nov 2026, so it no longer gets a phone crop (`HERO_PHONE_MAX = 0`; the code stays for a full-screen hero);
  - `en/index.html` and `zh/index.html`: the same page with English or Chinese as the default (`LANGS` in the build lists the languages: `lang`, `data-lang`, `<title>` and `og:title` from `data-title-CODE`, meta and og description from `data-desc-CODE` on `.site` (or, without it, that language's text of the hero's `.lead`), `og:image:alt` from the hero's `data-alt-CODE`, `og:locale` and its alternates, `og:url` and canonical on `https://mhs.mn/CODE/`, relative paths moved up one folder);
  - hreflang links on every page (mn → `https://mhs.mn/`, en → `https://mhs.mn/en/`, zh → `https://mhs.mn/zh/`, x-default → `https://mhs.mn/`), `data-href` on the МН/EN/CN buttons so they switch address, and a small `<head>` script that sends the old `?lang=xx` / `#xx` links and a saved choice to the right folder;
  - one language per published page: `one_language()` removes the other languages' `<span lang="…">` elements, so search engines and AI tools that ignore CSS read only Mongolian at `/`, only English at `/en/` and only Chinese at `/zh/`. `docs/index.html` keeps all three.
- `tools/zone_drawings.py` draws the five machines of the protected-zones selector (side elevations in metres at real proportions, zones per machine) and writes them into `docs/index.html`. It is run by hand, not by the build. Change a drawing there, not in the SVG. The hatch pattern `#zh` lives once in the zero-size `<svg class="zdefs">` beside the tabs, so hidden tabs keep their hatching.
- Never commit generated files to `docs/` (no `docs/en/`, no `-800w`/`-phone` photo copies) — the build makes them on every deploy. `_site/` is the local build output and is ignored.
- The build must never fail because the page changed: anything it does not recognise is published unchanged with a `WARNING` line in the build output. Keep it that way, and read the log after changes to the page structure.
- Photo boxes: `sizes` comes from the slot boxes measured in Chromium (`BOXES` and the tall numbers in `tools/build_site.py`; slot kinds by figure class: hero, card, tall, wide, step, tile, detail, pair, feature; a step may carry its own box aspect when the box changes shape). If you change slot CSS (aspect-ratio, grid columns, gutters, `.wrap` width, hero padding or hero text length by a lot), re-measure and update those numbers, then check which `srcset` candidate is picked at DPR 1, 2 and 3. A new kind of slot is left without `srcset` (with a warning) until the build knows its box.
- Fonts are self-hosted in `docs/fonts/` (copies of the Google Fonts files from the @fontsource packages, SIL OFL; keep the `LICENSE-*.txt` files). The `@font-face` rules are inline at the top of the `<style>` with `unicode-range` and `font-display: swap`. Mongolian needs the cyrillic and cyrillic-ext subsets (Ө ө Ү ү) plus latin. Preload only the two first-screen files (Fira Sans Extra Condensed 800 and IBM Plex Sans, cyrillic); the build swaps them to latin on `/en/` and `/zh/`. No Google Fonts links. Chinese glyphs are not self-hosted: `.site[data-lang="zh"]` appends the reader's system CJK faces (PingFang, Microsoft YaHei, Noto Sans CJK) to the three font stacks, so Latin and digits stay in the site fonts.
- Three languages: every visible string exists three times, as `<span lang="mn">…</span><span lang="en">…</span><span lang="zh">…</span>`, written exactly like that (no other attributes on those spans): the build finds them by that tag. Mongolian is the default (`data-lang="mn"` on `.site`). Placeholders, alt text and aria labels use `data-ph-mn/en/zh`, `data-alt-mn/en/zh` and `data-aria-mn/en/zh`; the quote form's needs use `data-mn/en/zh` and its labels live in `LABELS` in the script. Keep `data-title-mn/en/zh`, `data-desc-en` and `data-desc-zh` on `.site` and the English and Chinese spans in the hero's `.lead` — the English and Chinese pages' titles and descriptions come from them. Chinese is Simplified, in the register of a mining-industry supplier. Brand and product names stay in Latin, except that DAFO and SENNEBOGEN carry their Chinese names in brackets in the Chinese title, description and first mentions — DAFO（达弗）, SENNEBOGEN（森尼伯根） — and the machine brands in the Chinese track record carry theirs (CAT（卡特彼勒）, XCMG（徐工）…) (owner, 7 Nov 2026).
- Show only DAFO and SENNEBOGEN as official partners.
- `docs/ef8d0dd29fefc4380d8930910c1606e7.txt` is the site's IndexNow key (Bing and other IndexNow search engines check it before accepting a crawl request for mhs.mn). Don't delete or rename it.
- `docs/llms.txt` (a plain-text summary for AI tools, published at https://mhs.mn/llms.txt) and the JSON-LD block in `<head>` restate the page's facts: names, contact, hours, where MHS works, services, the track record (the machine models fitted; no counts since 28 Nov 2026). When one of those facts changes on the page, change it in both. Mark up only what the page shows.
- Never name customers — in text, alt text or photos. References stay as machine types, models and counts. Before adding a photo, check machine bodies and truck canopies for painted company names or logos and remove them: the repository is public and its history keeps every file ever committed.
- Photos live in `docs/photos/` and are linked with relative paths (`photos/…`). Keep them about 2000 px wide or less and compressed (JPEG; the build only makes copies of JPEGs); use `loading="lazy"` below the first screen. The owner replaces a photo by uploading a file with the same name; nothing else is needed.
- `docs/og-image.jpg` is the link-preview picture (1200×630, cropped from the hero photo, used by `og:image` on both pages). Regenerate it if the hero photo changes, and keep `<title>`, `og:title` and `og:description` in step with the page's wording.
- Keep `data-build="live"` on the `.site` div.
- Videos are plain links to YouTube (`.vid` tiles: play icon, bilingual title, `target="_blank" rel="noopener"`, hidden "opens in a new tab" text), never embedded players, which would load Google's scripts and cookies.
- The quote form only builds an email (mailto) — there is no server. Keep it that way unless the user asks for a form service.
- Do not delete `docs/CNAME` (`mhs.mn`, a leftover of GitHub Pages, harmless), `docs/404.html` (the site's not-found page) or `docs/_headers` (Cloudflare Pages header rules: noindex on mhs-mn.pages.dev only). Keep URLs in `robots.txt` and `sitemap.xml` on `https://mhs.mn/`; the sitemap lists `/` and `/en/` with hreflang alternates — bump both `<lastmod>` when content changes.
- Before committing, run `python3 tools/build_site.py docs _site`, serve `_site/` (e.g. `python3 -m http.server -d _site`) and open `/` and `/en/` at desktop and phone widths: every image loads, no warnings, the MN/EN switch changes address.
